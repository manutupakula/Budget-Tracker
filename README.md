# Budget Tracker App 💰

A personal finance web app built using HTML, CSS and JavaScript with Chart.js for data visualization.

## About the Project 💻

I built this as a beginner-friendly finance tracker to understand how real web apps work before jumping into frameworks like React.

All data is saved in the browser's LocalStorage so your transactions stay even after you close and reopen the tab.

## Features ⚙️

- Add income and expense transactions
- 12 category options with emoji icons
- Donut Chart for income vs expense
- Bar Chart for 6-month comparison
- Category breakdown
- Real-time summary cards
- Filter transactions
- Delete transactions
- Clear all transactions
- Dark / Light mode toggle
- Fully responsive

## Tech Stack 🌐

| Technology | How it's used |
|-----------|---------------|
| HTML5 | Page structure |
| CSS3 | Styling, theming |
| JavaScript | App logic |
| Chart.js | Data visualization |
| LocalStorage API | Data persistence |
