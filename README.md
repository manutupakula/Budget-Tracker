# Budget Tracker (HTML/CSS/JS) 💰

A personal finance web app built with pure **HTML, CSS and JavaScript** — no frameworks, no build tools needed. Just open the file and it works!

## Features

- Add income and expense transactions with categories
- Donut chart — income vs expense breakdown
- Bar chart — last 6 months overview
- Category breakdown with progress bars
- Dark / Light mode toggle
- Filter by All / Income / Expense
- Delete transactions
- Data saved in LocalStorage

## How to Run

1. Unzip the folder
2. Open `index.html` in your browser
3. Done — no installation needed!

## Tech Used

- HTML5, CSS3, Vanilla JavaScript
- Chart.js (via CDN)
- LocalStorage API
